# Compañero de Comunicación y Rehabilitación para Afasia Post-ACV

Producto móvil de asistencia comunicativa y rehabilitación del lenguaje para un adulto
intelectualmente capaz con afasia adquirida tras un ACV.

> **Estado del proyecto: INVESTIGACIÓN. No se escribe código de producto.**
> No existe app, ni esquema de base de datos, ni proveedor contratado.

## Principio rector

> Preservar la complejidad del pensamiento. Reducir la fricción del lenguaje. Restaurar la comunicación.

**Afasia ≠ pérdida de inteligencia.** El sistema modela por separado la *complejidad de contenido*
y la *complejidad de lenguaje*: mantiene la idea compleja y andamia el lenguaje.
